# Мини-приложение «Расписание занятий» для Telegram

Тёмное приложение с расписанием: переключатель недель, дни недели (пн–сб),
карточки пар с временем, типом (лек/пр/лаб/конс), преподавателем и аудиторией.
У лабораторных указывается подгруппа (1 или 2): пара показывается одним общим
блоком со временем, а внутри него — отдельный блок на каждую подгруппу
(если у подгруппы в это время пары нет — показывается «Нет пары»).
Если название предмета не заполнено — в карточке полупрозрачным серым
цветом автоматически показывается «Нет пары».

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | Разметка приложения |
| `css/style.css` | Стили (тёмная тема, цвета — из примера-скриншота) |
| `js/data.js` | **Данные: группа, баннер, само расписание. Единственный файл, который нужно менять** |
| `js/app.js` | Логика отрисовки и интеграция с Telegram |
| `background.jpg` | Фон приложения (слой затемнён полупрозрачным оверлеем) |

## Как открыть локально

Просто открой `index.html` двойным щелчком в браузере — сервер не нужен.

Или через локальный сервер (если запущен): <http://localhost:8088>

## Как изменить расписание

Открой `js/data.js` — внутри всё описано. Каждая пара:

```js
{ start: "08:00", end: "09:35",
  title: "Название предмета",
  teacher: "ст.пр. Некало И.А.",
  room: "а.713, к.21",
  type: "лек" }         // "лек" | "пр" | "лаб" | "конс"
// для "лаб" можно добавить подгруппу:
// subgroup: 1          // 1 или 2
```

Расписание лежит в `SCHEDULE[номер недели][день]`, дни: `"пн" … "сб"`.
Пустой массив `[]` — дней без занятий (показывается «Занятий нет»).

Править данные можно и прямо в приложении: кнопка **✏️** в шапке —
тип пары, подгруппа лабораторной, экспорт готового `js/data.js`
(копируется кнопкой «Скопировать» — замени им файл на GitHub).

## Авто-обновление `js/data.js` (GitHub)

Чтобы правки в приложении сразу попадали в файл `js/data.js` репозитория
(а не только в память браузера):

1. Создай **fine-grained** токен: <https://github.com/settings/personal-access-tokens>
   → **Generate new token**.
   - **Repository access** → Only select repositories → `MaksusBY/kai`.
   - **Permissions → Repository permissions → Contents** → **Read and write**.
   - Сгенерируй и скопируй токен (показывается один раз).
2. В приложении открой редактор (✏️ в шапке) → раздел
   **«Авто-обновление data.js (GitHub)»** → вставь токен в поле.
3. Убедись, что переключатель стоит на **«Включено»**.

После этого каждое изменение расписания (добавление/правка/удаление пары,
шапка, очистка) с задержкой ~1.2 с само коммитится в `js/data.js`.
Кнопка **«Сохранить в GitHub сейчас»** отправляет принудительно.
Статус виден строкой ниже.

Токен хранится в `localStorage` только этого браузера и в код репозитория
не попадает. Если токен кто-то узнает — отзови его на той же странице
GitHub. При смене устройства токен нужно ввести заново.

## Как выложить на GitHub Pages

1. Зарегистрируйся на <https://github.com> (если ещё нет).
2. Справа вверху: **+ → New repository** → имя (например `schedule-app`),
   выбери **Public** → **Create repository**.
3. На странице репозитория: **Add file → Upload files** → перетащи
   `index.html`, папку `css` и папку `js` → **Commit changes**.
4. Вкладка репозитория **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main**, folder: **/(root)** → **Save**.
5. Через 1–2 минуты приложение будет доступно по адресу вида
   `https://ИМЯПОЛЬЗОВАТЕЛЯ.github.io/ИМЯРЕПОЗИТОРИЯ/`
   — это и есть HTTPS-адрес, который понадобится для BotFather.

## Как создать бота и открыть приложение в Telegram

1. В Telegram найди **@BotFather** → команда `/newbot` → придумай имя →
   придумай логин (должен заканчиваться на `_bot` или `Bot`).
2. BotFather пришлёт **токен** — сохрани его, никому не показывай.
3. Команда `/newapp` → выбери своего бота:
   - **App name** — например `Расписание`
   - **Short name** — латиницей, например `schedule`
   - **Description** — любое
   - **Photo** — можно пропустить (Enter)
   - **URL** — вставь адрес со шага 5 выше (GitHub Pages)
4. Команда `/setmenubutton` → выбери бота → вставь тот же URL.
   Это кнопка меню рядом с полем ввода: по ней приложение и открывается.
5. Проверь с телефона: открой бота → нажми кнопку меню (иконка слева
   от поля ввода) → приложение откроется внутри Telegram.
