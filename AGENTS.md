# Расписание занятий — Telegram Mini App

Веб-приложение с расписанием пар, показывается **внутри Telegram** как
Mini App. Живёт на GitHub Pages, без backend.

## Ключевые факты

- Репозиторий: `MaksusBY/kai`, ветка `main`.
- Живой адрес: https://maksusby.github.io/kai/
- Любые правки попадают в Telegram после `git push` в `main`
  (~1–2 минуты на пересборку Pages). Код в Telegram не копируется —
  Mini App каждый раз открывает ссылку, поэтому ссылку у **BotFather**
  менять не нужно.
- Редактор принадлежит владельцу: `OWNER_ID = 791310922` в `js/app.js`
  (кнопка «✏️» видна только ему; вне Telegram доступен вход `?edit=1`).

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Разметка. Подключает `css/style.css?v=N` и `js/app.js?v=N` |
| `css/style.css` | Вся вёрстка и тема (цвета — CSS-переменными в `:root`) |
| `js/data.js` | Данные: `meta` (banner/group/course/defaultWeek), `days`, `SCHEDULE[неделя][день]`, поле `version`. Это «контент» |
| `js/app.js` | Отрисовка, редактор, интеграция Telegram, авто-коммит на GitHub, авто-обновление данных |
| `*.jpg` | Обои фона (`body::before` в CSS) |

Структура пары: `start`, `end`, `title`, `teacher`, `room`,
`type` (`лек`|`пр`|`лаб`|`конс`); у лаб — подгруппа `subgroup` (1|2).
Подробнее — в `README.md`.

## Правила правок (обязательно)

1. **После изменения `css/style.css` или `js/app.js` подними номер `?v=N`**
   в ссылках в `index.html` (например `app.js?v=6`, `style.css?v=3`).
   Иначе кэш WebView у пользователей покажет старую версию.
2. **Данные и версия.** В `js/data.js` есть числовое поле `version`
   (метка времени). При ручной правке `data.js` — всегда увеличивай
   `version`, иначе устройства с более новой локальной копией не обновятся.
   Через редактор версия проставляется автоматически.
3. **Механизм обновления.** Рабочая копия данных — `localStorage`
   (`scheduleApp:v1`). При открытии `app.js` запрашивает свежий
   `js/data.js` в обход кэша (`fetch("js/data.js?ts=" + Date.now())`)
   и применяет его, если `version` новее локальной. Это делает правки
   расписания видимыми всем без чистки кэша.

## Дизайн (текущая система, её нужно сохранять)

- Тёмная тема. Все цвета — переменные в `:root` в `css/style.css`:
  `--bg #0A0E0C`, `--surface`, `--text`, `--accent`, бейджи типов и др.
- Стиль: матовое стекло (`blur`), карточки пар скруглены 14px, время слева,
  активные вкладки — светло-небесные `rgba(154,208,250,.22)` с текстом
  `#AFEEEE`; баннер янтарный `#FFD030` со свечением.
- Макет: максимум 640px по центру, учтены safe-area инсеты
  (`env(safe-area-inset-bottom)`), `viewport-fit=cover`.

## Проверка

- Локально: открыть `index.html` в браузере (можно просто файлом).
  node/python в системе нет — при необходимости поднять простой сервер
  на `http://localhost:8099/` через PowerShell `HttpListener`.
- После деплоя: открыть живую ссылку и убедиться, что расписание
  рендерится и в консоли нет ошибок.

## Пожелания пользователя

- Пользователь будет просить переделывать/менять дизайн. Начинать с
  текущей дизайн-системы выше и сохранять её стиль, если не сказано иначе.
- Правки нужно не только показывать, но и публиковать: закоммитить,
  запушить в `main` и подтвердить, что GitHub Pages отдал новую версию.
